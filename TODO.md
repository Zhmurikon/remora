# TODO Remora

Этот файл — единый источник текущего прогресса проекта. Подробные требования находятся в
[`docs/02-functional-spec.md`](docs/02-functional-spec.md), порядок этапов — в
[`docs/03-roadmap.md`](docs/03-roadmap.md).

Правила ведения:

- `[x]` означает, что задача реализована и проверена.
- `[ ]` означает, что задача не завершена или ещё не проверена полностью.
- После каждого изменения проекта этот файл обновляется в том же коммите.
- Новые обнаруженные задачи добавляются в соответствующий раздел до завершения работы.
