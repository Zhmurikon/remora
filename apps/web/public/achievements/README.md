# Иллюстрация достижений

`achievement-placeholder.webp` — точная копия общей заглушки из кабинета.
`achievement-first-published-course.webp` — согласованная иллюстрация достижения за первый
опубликованный курс. Обе копии используются публичным профилем через Next Image; оригиналы
для кабинета находятся в `apps/app/src/features/achievements/assets`. При замене обновлять
обе копии.
