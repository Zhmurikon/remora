# Оформление Telegram-канала «Запоминальни»

Публичный канал: `https://t.me/zapominalnya`.

На 27 октября 2026 года установлены:

- название «Запоминальня»;
- аватар `assets/social/vk/avatar-generated.png`;
- описание: «Карточки, курсы и интервальные повторения. Создавайте материалы, учитесь
  регулярно и возвращайтесь к сложному вовремя. zapominalnya.ru»;
- приветственный пост с иллюстрацией `assets/social/vk/pinned-post.png`, кнопкой перехода
  на сайт и закреплением без дополнительного уведомления.

Текст закреплённой публикации хранится в `pinned-post.md`.

Для управления создан отдельный бот `@zapominalnya_channel_bot`. Его токен хранится только
в локальном `.env` под именем `CHANNEL_TG_BOT_TOKEN`. Боту оставлены права на изменение
профиля канала, публикацию, редактирование и закрепление записей. Удаление сообщений,
управление подписчиками, администраторами, звонками и историями отключено.
