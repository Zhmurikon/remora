# Оформление сообщества «Запоминальни» во ВКонтакте

Комплект собран в цветах и типографике продукта. Для аватара выбран отдельный знак,
сгенерированный с нуля под круглую миниатюру ВКонтакте.

## Файлы

- `cover.png` — основная обложка сообщества, 1920 × 768;
- `avatar.png` — круглый аватар с прозрачностью за пределами окружности, 800 × 800;
- `avatar-generated.png` — выбранный новый знак, созданный с нуля для аватара сообщества,
  1254 × 1254 с прозрачностью за пределами окружности;
- `avatar-generated.prompt.txt` — промпт, по которому создан выбранный знак;
- `menu-*.png` — четыре плитки меню, 752 × 512;
- `pinned-post.png` — обложка закреплённой записи, 1080 × 1350;
- `pinned-post.md` — опубликованный текст закреплённой записи;
- одноимённые SVG — редактируемые исходники;
- `generate.mjs` — воспроизводимая сборка всего комплекта.

Пересборка из корня проекта:

```bash
node assets/social/vk/generate.mjs
```

Текст и значимые элементы обложки находятся в центральной зоне, чтобы сохраняться при
мобильном кадрировании. Перед повторной загрузкой размеры нужно сверить с подсказками редактора
ВКонтакте: платформа периодически меняет требования к носителям.

## Установлено в сообществе

На 27 октября 2026 года в `vk.ru/club241551749` установлены `cover.png` и
`avatar-generated.png`. Название изменено на «Запоминальня», добавлены описание,
ссылка на сайт, кнопка «Открыть сайт», приветствие сообщений и офлайн-ответ.
Публикация смены аватара отдельным постом отключена. Приветственная запись опубликована
как `wall-241551749_1` и закреплена.

Статус сообщества остаётся пустым: метод `status.set` недоступен токену сообщества,
а в текущем интерфейсе управления отдельное поле статуса не показывается. Если VK вернёт
такое поле, установить текст «Учитесь регулярно. Помните дольше.».
