# Бренд-ассеты Remora

Это полный набор утверждённого логотипа Remora. Знак нельзя перерисовывать, менять его
пропорции, цвета или добавлять эффекты.

## Содержимое

- `source/` — утверждённый исходный растр персонажа;
- `mark/` — полный и компактный знаки на прозрачном фоне в SVG и PNG;
- `lockups/` — горизонтальные и вертикальные логотипы с названием, обычные и инверсные;
- `icons/` — favicon, Apple Touch Icon, обычные и maskable PWA-иконки.

Основные цвета: бирюзовый `#0D8285`, белый `#FFFFFF`, оранжевый `#EA8D2F`.
Обычные логотипы предназначены для светлого фона, варианты `*-inverse` — для тёмного.
Компактный знак `remora-mark-compact.*` показывает лицо и верхнюю часть книги; он используется
в размерах до 48 px, favicon и иконках приложений. Полный знак используется в крупных логотипах.

## Обновление

Все производные файлы пересобираются из корня проекта:

```bash
scripts/generate-brand-assets.sh
```

Скрипт одновременно обновляет этот каталог и рабочие копии в `packages/ui`, `apps/web`,
`apps/app` и `apps/mobile`. Не редактируйте экспортированные файлы вручную.
