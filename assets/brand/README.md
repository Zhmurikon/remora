# Бренд-ассеты «Запоминальни»

Публичное название пишется `Запоминальня`. Латинское `Zapominalnya` используется только там,
где кириллица технически невозможна. Основной домен — `zapominalnya.ru`.

Это полный набор утверждённого логотипа «Запоминальни». Знак нельзя перерисовывать, менять
его пропорции, цвета или добавлять эффекты.

## Содержимое

- `source/` — утверждённый исходный растр персонажа;
- `mark/` — полный и компактный знаки на прозрачном фоне в SVG и PNG;
- `lockups/` — горизонтальные и вертикальные логотипы с названием, обычные и инверсные.
  Основные файлы начинаются с `zapominalnya-`; прежние пути `remora-logo-*` временно содержат
  те же новые компоновки для совместимости клиентов;
- `icons/` — favicon, Apple Touch Icon, обычные и maskable PWA-иконки.

Основные цвета: бирюзовый `#0D8285`, белый `#FFFFFF`, оранжевый `#EA8D2F`.
Обычные логотипы предназначены для светлого фона, варианты `*-inverse` — для тёмного.
Компактный знак `remora-mark-compact.*` показывает лицо и верхнюю часть книги; он используется
в размерах до 48 px, favicon и иконках приложений. Полный знак используется в крупных логотипах.
Имя `remora` в файлах знака сохранено как внутренний технический идентификатор и не является
публичным названием.
`mark/remora-google-oauth.png` — квадратный PNG 120 × 120 px для экрана согласия Google OAuth.
Он собран из утверждённого компактного знака и соответствует требованиям Google Cloud.

## Обновление

Все производные файлы пересобираются из корня проекта:

```bash
scripts/generate-brand-assets.sh
```

Скрипт одновременно обновляет этот каталог и рабочие копии в `packages/ui`, `apps/web`,
`apps/app`, `apps/admin` и `apps/mobile`. Не редактируйте экспортированные файлы вручную.
