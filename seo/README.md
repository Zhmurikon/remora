# Поисковое ядро Remora

Версия: 2 октября 2026 года.

Ядро собрано для русскоязычной аудитории Remora в России: прежде всего студентов, которые
готовятся к экзаменам, превращают конспекты в вопросы и повторяют материал по карточкам.
Основная поисковая система для исследования — Яндекс; структуру страниц стоит проверять и в
Google после открытия публичной индексации.

## Что лежит в папке

- `keyword-core.csv` — 114 запросов с кластером, частотностью, интентом, страницей и
  приоритетом.
- `landing-pages.md` — карта главной и посадочных страниц, границы интентов и порядок запуска.
- `blog-plan.md` — кластеры блога и очередь из 32 статей, включая три уже опубликованные.
- `top-10-articles.md` — десять следующих статей с готовыми редакционными брифами.
- `research-notes.md` — методика, источники, правила проверки частотности и минус-слова.

## Как читать частотность

Четыре запроса имеют числа из Wordstat, ранее переданные владельцем и сохранённые в
`docs/09-homepage.md`. Регион, устройство и тип соответствия для них неизвестны, поэтому числа
нельзя складывать или использовать как прогноз трафика.

Для остальных запросов класс «ВЧ / СЧ / НЧ» — относительная оценка внутри ниши карточек и
учебных сервисов. Она основана на длине запроса, поисковом интенте, подсказках Яндекса и составе
выдачи. В CSV такие строки имеют уверенность `оценка`, а поле числовой частоты пустое.

Перед созданием страницы нужно снять Wordstat для России и приоритетных регионов:

1. широкую частоту — запрос без операторов;
2. фразовую — запрос в кавычках;
3. точную — запрос в кавычках и квадратных скобках;
4. сезонность за два года;
5. десктоп и мобильные устройства отдельно, если данные заметно расходятся.

Рабочие диапазоны для этой ниши: ВЧ — от 1 000 показов в месяц, СЧ — 200–999, НЧ — до 199.
После полного съёма границы стоит пересчитать по медиане и квартилям фактического списка.

## Основное решение

Главная получает коммерческий кластер «карточки для запоминания / флеш-карточки / карточки для
учёбы». Отдельную страницу под общий запрос «флеш-карточки» пока не создаём: её интент совпадает
с главной и может вызвать каннибализацию.

Первый выпуск посадочных:

1. создание карточек онлайн;
2. интервальное повторение;
3. карточки для английских слов;
4. подготовка к экзамену;
5. карточки для студентов;
6. российский бесплатный аналог Quizlet;
7. импорт из Anki;
8. карточки из конспекта.

Страницы про ИИ-генерацию из PDF, фото или аудио в ядро продаж не включены: Remora пока не
предлагает такую встроенную функцию. Их можно добавить после реализации продукта, а не раньше.

## Правило одной страницы

У каждого запроса в CSV одна целевая страница. Вариации используются в заголовках и тексте
естественно, без отдельной страницы на каждую формулировку. Новый URL появляется только тогда,
когда у запроса другой интент, своя полезная функция или достаточно самостоятельный материал.
