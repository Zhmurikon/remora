# Три концепта страницы курса

[А — Обложка и оглавление](a.png) · [Б — Книжный разворот](b.png) · [В — Папка с разделителями](c.png)

Ширина всех макетов — 1440 CSS px. Для сравнения взят один вымышленный курс. Названия, автор, счётчики и текст карточки в макетах иллюстрируют поля шаблона. Шапка и подвал взяты из локальной главной.

- **А.** Сначала читатель знакомится с курсом, затем выбирает статью в содержании слева. На телефоне содержание сворачивается перед статьёй.
- **Б.** Сведения о курсе занимают левую страницу разворота, оглавление и статья — правую. На узком экране колонки читаются сверху вниз. Для длинного описания предусмотрено раскрытие полного текста.
- **В.** Разделы переключаются закладками, карточки относятся к открытой статье. Если закладки не помещаются, вместо ряда появляется список разделов. На телефоне карточки располагаются под текстом.

При вёрстке заголовки переносятся целиком, количество разделов и статей берётся из данных. Для курса с единственной статьёй переходы между статьями не нужны. Отсутствующие описание, теги, карточки и похожие курсы освобождают своё место. Курс без разделов сохраняет обложку, сведения об авторе и действия с курсом.

Во всех композициях для открытой статьи нужны исходные якоря, форматированный текст, таблицы, формулы, изображения, сохранение и копирование статьи и набора. Список карточек предусматривает подсказки, транскрипцию, загрузку продолжения и повтор при ошибке. Рисунки относятся к учебным материалам вообще, выбор иллюстрации не зависит от предмета курса.
