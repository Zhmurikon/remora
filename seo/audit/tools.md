# Инструменты и доступы для аудита

Состояние проверено **12.11.2026**. Короткий прогон проверяет инструмент, а не качество всего сайта. Команды ниже выполнять из корня репозитория. Инструменты аудита не входят в зависимости продукта и не требуют запуска API, базы или доступа по SSH.

## Первый воспроизводимый прогон

Создать новый каталог для серии: команды ниже предполагают Bash. Не переиспользовать старое имя. Обход выполняется только по команде; регистрации, отправки на переобход и публикации не происходит.

```bash
umask 077
mkdir -p seo/audit/runs seo/audit/exports
run_dir=$(mktemp -d "seo/audit/runs/$(date +%F)-baseline-XXXXXX")
uv run --locked --script seo/audit/tools/crawl.py --limit 100 > "$run_dir/crawl.jsonl"
```

Обход идёт без авторизации, на одном origin, последовательно с паузой не менее секунды; учитывает robots и Crawl-delay, не переходит по внешним редиректам. Сначала читает XML-карты, затем объединяет их URL с публичными HTML-ссылками. Лимит относится к GET страниц, сверх него идут служебные запросы robots/sitemap. Список семейств в скрипте явный: приватные пути, query-варианты, внешние ссылки и медиа автоматически не обходятся. Новые маршруты надо сначала сверить с реестром; внешние ссылки, параметры, атрибуты rel, анкоры, ресурсы и JS-ссылки проверяем отдельно. Не подставлять приватные slug или подписанные URL в публичные сервисы.

Код завершения **0** — очередь разрешённых адресов обработана; **1** — остались URL или были ошибки отдельных запросов; **2** — прогон остановлен (например, HTTP 429/5xx или непрочитанная карта). При неполном прогоне не делать выводов о сиротах или долях всего сайта. Для остановленного прогона сначала разобрать причину, для ограниченного — записать остаток и выбрать новый лимит в отдельном каталоге. События `page` содержат HTTP-ответ, в том числе 3xx/4xx; код 0 сам по себе не означает отсутствие SEO-дефектов. `blocked` означает запрет для агента аудита, а не статус индекса Google или Яндекса.

```bash
jq -c 'select(.kind=="end" or .kind=="aborted" or .kind=="error")' "$run_dir/crawl.jsonl"
jq -r 'select(.kind=="sitemap") | .url' "$run_dir/crawl.jsonl" | sort -u > "$run_dir/sitemap-urls.txt"
jq -r 'select(.kind=="page") | [.url,.status,.location,(.canonical // [] | join(" | ")),(.title // [] | join(" | "))] | @csv' "$run_dir/crawl.jsonl" > "$run_dir/pages.csv"
jq -r 'select(.kind=="link") | [.source,.target] | @csv' "$run_dir/crawl.jsonl" > "$run_dir/edges.csv"
python3 seo/audit/tools/link_depth.py "$run_dir/crawl.jsonl" > "$run_dir/link-depth.csv"
pnpm --filter @remora/web test src/app/seo.test.ts
```

У `pages.csv` поля URL, HTTP, Location, canonical, title; у `edges.csv` — источник, цель. Строки без заголовка. `sitemap` и `link` — разные источники обнаружения. У `link-depth.csv` есть заголовки: URL, наличие в карте, число других страниц с прямой HTML-ссылкой, минимальное число кликов от главной. Редирект не добавляет клик. Пустая глубина у страницы из карты — кандидат на ручную проверку по реестру и в браузере; самоссылки не учитываются как входящие. Если используете локальный сайт, укажите его корневой URL через `--root`. Наличие записи `page` не означает достижимость от главной. Краулер не рендерит JS и не заменяет проверку применимости разметки или фактического индекса.

Для одного адреса и одного старого перехода (GET, без cookies и автоматического перехода на новый адрес):

```bash
curl -sS --max-time 20 -D "$run_dir/catalog.headers" -o "$run_dir/catalog.html" 'https://zapominalnya.ru/kursy'
curl -sS --max-time 20 -o /dev/null -w '%{http_code} %{redirect_url}\n' 'https://remora.com.ru/kursy?utm_source=seo-check'
```

Для сравнения статического и отрисованного содержимого открыть каталог в новом гостевом окне Chrome, сравнить Network → Document → Response и Elements: текст, H1, ссылки навигации, canonical, robots и `script[type="application/ld+json"]`. Повторить на мобильном профиле, затем с отключённым JavaScript. В отчёте указать, какой именно слой был проверен.

Для измерения быстродействия передавать адрес непосредственно проверяемой страницы. Вручную сопоставить конечный URL из медиан с ожидаемым — редирект на главную сделает измерение курса бессмысленным.

```bash
bash seo/audit/tools/vitals.sh 'https://zapominalnya.ru/kursy' "$run_dir/lh-kursy"
```

Команда создаёт новый каталог, проверяет шесть JSON-отчётов, сохраняет версии и `medians.json`. Прерывается при ошибке загрузки. Зафиксировать сеть, машину, дату и URL; при сравнении не менять профиль и не запускать нагрузочную работу параллельно. Полный Lighthouse JSON содержит адреса ресурсов и остаётся в `runs/`.

## Какие данные нужны к этапу 01

Запрашиваем права **на просмотр** либо файлы, без паролей и токенов. Окна: два последовательных полных периода по 28 дней, до 90 дней для тенденций, предыдущий год при наличии. Каждый экспорт сопровождается ресурсом/доменом, датой выгрузки, точными границами, часовым поясом, фильтрами, типом поиска и ограничениями по строкам.

| Источник                                                  | Минимальный экспорт                                                                                                                                                         | Для чего                                                                                                                              |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| GSC и Вебмастер, отдельно для каждого домена и поисковика | Итоги по дням; запросы и посадочные с показами, кликами, CTR и позицией; срезы страна/регион и устройство, если доступны.
