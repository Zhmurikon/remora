# Три независимые рецензии на текст главной

Все три рецензента получили один [исходный текст](06-homepage-sections.md). Ниже их замечания и предложенные формулировки. Решения для макета собраны в [итоговой редакции](08-homepage-copy.md).

## Литературный критик

| Блок | Замечание | Предложенная правка |
|---|---|---|
| 1 | «Запоминальня запоминает» звучит как непреднамеренная игра слов. | «По вашим ответам сервис определит, какие карточки пора повторить». |
| 2 | Фраза «подписать его отделы» создаёт впечатление, что в редакторе можно рисовать поверх изображения. | «Добавьте на одну сторону схему сердца с пронумерованными отделами, на другую — их названия». |
| 3 | «Дайте ответ» скрывает разницу между письмом и аудированием. | «Прослушайте слово и запишите, что услышали». В примере письма дать перевод и оставить написание слова упражнению. |
| 4 | Два вопроса подряд задерживают переход к каталогу. | Начать с предмета поиска и закончить одним конкретным действием. |
| 5 | Вводная фраза про место темы в оглавлении слишком общая. | Начать с фрагмента урока и дать читателю ответить на вопрос по памяти. |
| 6 | «Задайте карточки классу» звучит неестественно. Текст переключается с класса на группу. | «Что повторить с классом на следующем уроке». Дальше использовать «класс» и «ученики». |
| 7 | «Бот связан» пропускает действие пользователя. Пример «утром… вечером…» можно принять за задержку синхронизации. | «Привяжите бота к своему аккаунту. … Ответы из чата учитываются и в вашем кабинете». |
| 8 | «В пять раз больше объёма» трудно произнести. Количество предметов мало говорит о потребности в Pro. | «Недельный лимит на подготовку конспектов и карточек в пять раз выше, чем на Plus». |
| 9 | «Сохранит этот режим доступа» — служебная формулировка. | «Скрытые материалы останутся закрытыми и после окончания подписки». |
| 10 | Вводная «Здесь рассказываем…» повторяет заголовок. | Начать с дат и назвать действия, которые стали доступны в каждом выпуске. |

## SEO-специалист

| Приоритет и блок | Замечание | Предложенная правка |
|---|---|---|
| Высокий · 1–2 | Исходное определение «сервис для учёбы» можно сделать точнее. В локальном срезе Wordstat есть спрос на создание карточек и занятия онлайн. | Блок 1 — «Запоминальня — сервис, где можно создавать карточки для запоминания и заниматься по ним онлайн». Блок 2 — «Как создать карточки по своим материалам». |
| Высокий · 4 | Публичный каталог ищет курсы. Исходный текст обещает поиск отдельного набора по любой теме. | Для формы — «Найти курс». Для готовых материалов — прямые ссылки на действительно опубликованные набор и курс. Дать ссылку на подборку «К первому зачёту». |
| Средний · 1, 3 | Копирайт описывает интервальное повторение, но читатель может не узнать знакомый ему метод. | Один раз назвать метод рядом с объяснением, как сервис подбирает срок следующего повторения. |
| Средний · 4–5 | После каталога идёт учебный пример, который нельзя открыть по названию. | Показать опубликованный урок о трёх зонах Git из подборки и связать рассказ о курсе с этим уроком. |
| 6–10 | Сценарии класса и ботов уже достаточно конкретны. Страница тарифов существует. Отдельного публичного архива новостей в проекте нет. | Сохранить смысл сценариев, вести «Сравнить тарифы» на `/tarify`, оставить новости датированными заметками. В FAQ ответить прямо на вопросы о форматах и публичности. |

Основания — [исследование](01-research.md), [срез Wordstat](wordstat.csv), [выгрузка Search Console](gsc-queries.csv) и [код каталога](../../../apps/web/src/app/kursy/page.tsx). Оценку роста трафика эти данные не дают.

Сохранить сквозное слово drizzle в режимах. Для курса дать рабочую ссылку. Начать новости с подтверждённых выпусков. |

## Решения для макета

Сохранены все десять блоков и их порядок. Для разделов 4 и 5 выбран реальный курс по Git вместо примера о Японии: читатель может перейти от текста непосредственно к описанному уроку и его карточкам. В разделе о ботах обе ссылки на мессенджеры заменены одной кнопкой подключения в кабинете. Пояснение о бесплатном ручном вводе и импорте вынесено к выбору способа создания карточек.
