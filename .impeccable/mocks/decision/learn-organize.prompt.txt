Use case: ui-mockup
Asset type: high-fidelity responsive product-design concept board for Remora web app
Primary request: Create a landscape concept board for the “Учиться / Организовать” redesign of Remora’s courses, sets, and saved library. Show one large desktop web-app viewport on the left and one complete mobile responsive viewport on the right, both light theme, no device mockup and no decorative presentation frame. This is an operating interface, not a marketing page.
Reference image role: carry over Remora’s warm ivory paper ground, deep forest text, jade/teal controls, restrained coral/ochre status accents, editorial heading character, subtle dotted/leaf motifs, and calm flat component style. Do not copy the reference screen’s content or phone hardware.
Desktop structure: persistent left navigation with Remora logo and “Материалы” selected. Main title “Материалы” and one primary “Создать” button. Immediately below the title, a prominent segmented switch “Учиться” selected / “Организовать”. In “Учиться”, show a narrow summary sentence “Сегодня 31 карточка в 3 материалах” and a calm ranked single-column list grouped under “Сначала повторить”, then “Продолжить”, then “Стабильно”. Each wide row shows type, title, “Освоено 64%”, a thin progress bar, explicit urgency like “18 повторить сегодня”, last study date, and one clear button “Продолжить”. Add small filter chips “Все”, “Курсы”, “Наборы”, “Сохранённые”. Include a subtle explanatory hint that switching to “Организовать” reveals folders, drag order, editing, ownership and update management. On the far right of the desktop viewport, include a slim secondary panel titled “На этой неделе” with three upcoming review counts, not a generic analytics dashboard.
Mobile structure: top app bar, title, full-width “Учиться / Организовать” segmented control, compact daily summary, then a single-column priority list with the same progress and urgency labels; bottom navigation. Show a small glimpse of the unselected “Организовать” control state, but do not split the mobile screen into panes.
Composition: 16:9 wide board; desktop about 70% width, mobile about 25%; enough vertical content to prove scroll rhythm. Pixel-sharp, production-grade UI, readable Russian labels, coherent spacing.
Constraints: One dominant primary action. Progress never communicated by color alone. No gradients, no glassmorphism, no oversized KPI cards, no fake charts, no English interface text, no lorem ipsum, no watermark.
