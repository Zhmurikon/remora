Use case: ui-mockup
Asset type: high-fidelity responsive product-design concept board for Remora web app
Primary request: Create a landscape concept board for the “Навигатор знаний” redesign of Remora’s courses, sets, and saved library. Show one large desktop web-app viewport on the left and one complete mobile responsive viewport on the right, both light theme, no device mockup and no decorative presentation frame. This is an operating interface, not a marketing page.
Reference image role: carry over Remora’s warm ivory paper ground, deep forest text, jade/teal controls, restrained coral/ochre status accents, editorial heading character, subtle dotted/leaf motifs, and calm flat component style. Do not copy the reference screen’s content or phone hardware.
Desktop structure: persistent global left navigation with Remora logo and “Материалы” selected. Main workspace uses a second narrow hierarchy column titled “Мои материалы” with a search field and expandable groups: “Курсы”, “Самостоятельные наборы”, “Сохранённые”, “Архив”. Expand the course “Python для анализа данных” to reveal sections and sets. The large detail area to the right shows the selected course header, aggregate “Освоено 58%”, “31 карточка ждёт повторения”, and one button “Продолжить курс”. Directly below, show a vertical sequence of course blocks/sets with titles, card counts, thin progress bars, explicit text such as “Освоено 82% · всё по плану”, “Освоено 36% · 18 повторить сегодня”, and “Не начато”. Make the weakest nested set unmistakable with a slim coral rail and label “Проседает”, while retaining calm visual hierarchy. Include a small “Создать” action near the workspace title, not as a giant hero.
Mobile structure: replace the desktop hierarchy with a top breadcrumb “Материалы / Python для анализа данных”, compact course summary, and single-column nested set list. Provide a back action to the course/folder list and bottom navigation. Do not use a permanent drawer on mobile.
Composition: 16:9 wide board; desktop about 70% width, mobile about 25%; enough vertical content to prove hierarchy and scroll rhythm. Pixel-sharp, production-grade UI, readable Russian labels, coherent spacing.
Constraints: One dominant primary action. Progress never communicated by color alone. No gradients, no glassmorphism, no oversized dashboard KPI cards, no fake charts, no English interface text, no lorem ipsum, no watermark.
