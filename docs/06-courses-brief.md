# E6 — решения продуктового брифа

Этот документ заменяет прежние решения E6 о публичных наборах и дереве категорий.

Основная аудитория — студенты, основной сценарий — создание собственных материалов.
Публичная единица — курс: курс → раздел → статья → один набор карточек.
В курсе могут быть несколько разделов, статей и наборов.

Главная — продающая страница с преимуществами, поиском и демонстрационными карточками
(сначала заглушка). Каталог — отдельный раздел. Фильтры: предмет через теги, язык,
автор, число карточек, дата обновления и популярность. Теги независимые, без иерархии.

Популярность определяется сохранениями. Сигналы качества — лайки и сохранения.
Лайки доступны зарегистрированным пользователям. Публикация мгновенная с минимальными
требованиями; модерация после публикации. Жалоба сама по себе материал не скрывает.

Сохранять можно курс, статью или набор и учиться по связанному оригиналу.
Обновления применяются после просмотра изменений и нажатия «Обновить».
При снятии оригинала с публикации доступ у сохранивших исчезает.
Копирование курса или статьи с карточками создаёт независимую редактируемую копию.
Оригинал редактирует только автор. История версий и откат автору не нужны;
технические снимки для сравнения обновлений остаются необходимой частью сохранений.

Профиль автора: имя, публичные курсы и достижения (публикации, сохранения, лайки,
пройденные карточки, серия занятий, значки). Блог ведёт редакция Remora.
SEO охватывает курсы и материалы, теги, авторов, подборки и блог.
MCP-коннектор и ИИ-навык реализованы отдельным срезом по запросу владельца:
внешний агент генерирует теорию и карточки из источников и сохраняет их через API.
Подключение и ограничения описаны в [инструкции](07-agent-api.md).

## Очерёдность

E6A: минимальная оболочка курса из существующего набора, затем публикация курсов,
каталог и поиск, теги, профили, лайки, сохранения, SEO и постмодерация.
E6B: полноценный редактор разделов и статей, теория и копирование составных материалов.

По отдельному запросу владельца E6B реализован до завершения оставшихся задач E6A.
Доступны создание курса с нуля, редактор структуры/теории, чтение и переход к тренировке,
независимые копии курса и статьи (статья копируется в отдельный приватный курс).
Текущий чек-лист реализации и проверок находится в `TODO.md`.

Первый срез — приватный API создания курса с одним разделом, одной статьёй и существующим
собственным набором, список курсов, чтение структуры, изменение названия и описания.
Slug стабилен при переименовании. Создание курса само по себе не публикует его.
Переход старых публичных ссылок на курсы — отдельная задача E6A.
