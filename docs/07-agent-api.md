# Персональные токены, JSON API и MCP

## Подключение

В кабинете откройте «Настройки → API и ИИ-агенты». Создайте токен с названием,
сроком 30/90/365 дней и правами чтения/изменения материалов. Публикация по умолчанию
выключена. Секрет показывается только при создании; скопируйте его в защищённое
окружение процесса агента. В БД хранится SHA-256 случайного 384-битного секрета,
в списке — только префикс и метаданные. Отзыв запрещает новые запросы; уже начатая
транзакция может завершиться. Срок серверного API — от 1 до 365 дней, по умолчанию 90.

MCP-коннектор запускается локально по stdio. Установите зависимости через `uv sync`
в `apps/api`, затем настройте ваш MCP-клиент на запуск:

```text
command: uv
args: [run, --directory, /absolute/path/to/remora/apps/api, python, -m, app.mcp_server]
environment:
  REMORA_API_URL: http://localhost:8000
  REMORA_API_TOKEN: <значение из защищённого хранилища>
```

Это описание параметров, не универсальный формат конфигурации: синтаксис зависит
от MCP-клиента. API должен быть запущен отдельно. Указывайте origin без `/api/v1`.
Вне localhost нужен HTTPS. Коннектор не следует редиректам, не использует прокси
из окружения и передаёт токен только настроенному API. Реализация использует
[официальный Python SDK MCP v1](https://py.sdk.modelcontextprotocol.io/v1/), закреплённый
диапазоном `<2` и lock-файлом. Удалённый HTTP MCP/OAuth в этот срез не входят.

Готовый навык: `integrations/skills/remora-author`. Подключите эту папку как навык
в вашем агенте. Автоматическая установка в глобальные настройки не выполняется.
Навык самодостаточен, содержит JSON-контракт и правила безопасного обновления.
В справочниках навыка также описаны качество карточек и дистракторов обоих направлений,
поддерживаемые форматы теории/карточек, ограничения и отдельный сценарий публикации.
`references/example-course.json` — проверяемый пример входного объекта курса, не команда
автоматически создавать демонстрационные материалы.

Пример задания: «По этому конспекту создай приватный курс: разделы, краткая теория,
карточки и правдоподобные неверные ответы в обоих направлениях. Укажи источники».
Материалы читает и генерирует внешний агент. Remora не запускает модель и не принимает
исходные PDF напрямую через этот API. Созданный курс виден в «Моих курсах», теория —
на странице «Читать курс», карточки доступны для обучения и обычного редактирования.
Редактор E6B позволяет менять разделы, статьи и теорию через кабинет. Такие изменения
меняют revision агентского API: перед обновлением агент должен перечитать курс.

## Контракт и гарантии

JSON-контракт: [справочник навыка](../integrations/skills/remora-author/references/api.md).
OpenAPI автоматически публикуется на `/openapi.json`; типизированная схема коммитится.
MCP предоставляет 16 инструментов: чтение/создание/обновление наборов и курсов,
публикация/снятие, чтение/изменение структуры без перезаписи карточек, копирование курса
или статьи, явное удаление статьи или раздела и безопасная загрузка изображений.
Вся бизнес-логика общая с JSON API.

- Токен не подходит к API кабинета, авторизации, смены пароля или управления токенами.
  JWT кабинета не подходит к `/agent`. Проверяются владелец, статус аккаунта, срок и права.
- Новые наборы и курсы приватные. Публикация требует отдельного права и отдельного вызова.
  Для изменения опубликованного курса через агента сначала нужно снять публикацию.
- Создание/изменение курса атомарно: ошибка последней карточки откатывает всю операцию.
- Каждая запись требует `Idempotency-Key`; одинаковый повтор возвращает сохранённый ответ.
  Другой запрос с тем же ключом получает 409. Ключи общие для токенов одного пользователя.
  Они хранятся до удаления аккаунта; автоматическая очистка пока не реализована.
- PUT требует `revision` последнего чтения. Записи контента кабинета и агента сериализованы
  по владельцу. Устаревшая версия возвращает 409. Сохраняйте ID карточек ради прогресса.
- PUT полного курса заменяет полный список карточек. Пропуск удаляет карточку. Пропуск
  раздела/статьи отклоняется: удаление выполняется отдельной операцией. Можно добавлять,
  переименовывать, перемещать и менять порядок, сохраняя ID.
- Технические ограничения: 120 запросов в минуту на пользователя; 20 новых токенов в час.
  Это защита API, не лимиты обучения. Листы имеют offset/limit, максимум 100 за страницу.
- Теория поддерживает Markdown, таблицы, цитаты, ссылки, KaTeX, блоки кода и изображения
  `media:UUID`, без исполнения HTML. Внешние картинки напрямую не отображаются.
- `upload_image` / `POST /agent/media` принимает ровно один источник: публичный HTTPS URL
  или base64 с MIME. Требуются `materials:write` и идемпотентный ключ. URL проверяется против
  SSRF, редиректы запрещены, размер ограничен общим лимитом изображений. SVG санитизируется.
  Ответ содержит `markdown_reference`; ID можно использовать и в полях изображения карточки.

### Операции E6B

`get_course_structure` / `GET /agent/courses/{id}/structure` читает только структуру и теорию.
`update_course_structure` / `PUT` того же пути меняет их без замены карточек и позволяет
подключить свой свободный набор либо создать новый пустой. Существующие ID обязательны.
Его revision отличается от revision полного `get_course`: нельзя подставлять одну вместо другой.
Пустые разделы и курсы поддерживаются как черновики обоими вариантами API.

`copy_course` / `POST /agent/courses/{id}/copy` принимает `{}` или `{article_id}`.
Копирует свой или доступный опубликованный материал в приватный независимый курс, включая
изображения и неверные ответы. После копирования `get_course` возвращает полный материал.

`delete_course_article` / `POST /agent/courses/{id}/articles/{article_id}/delete` и
`delete_course_section` / `POST /agent/courses/{id}/sections/{section_id}/delete` требуют
`{revision, confirm: true}`. Используется revision структуры. Раздел удаляется со всеми
текстами статей; наборы, карточки и прогресс сохраняются. Публикация автоматически не снимается.
Все новые записи требуют materials:write и идемпотентный ключ, чтение — materials:read.

## Проверки

```bash
cd apps/api
uv run alembic upgrade head
uv run pytest tests/test_agent_api.py tests/test_mcp_server.py
uv run python -m app.mcp_server
```

Последняя команда требует настроенного окружения и ожидает MCP-клиент на stdin.
Никогда не вставляйте реальный токен в командную строку, документацию или Git.
