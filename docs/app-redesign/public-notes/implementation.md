# Публичный конспект: общий шаблон с курсом

18 ноября 2026 года. Владелец выбрал общий шаблон чтения, сохранив `/konspekt/[id]`.
Конспект не превращается в курс: данные, API, публичность и адреса остаются прежними.

## Реализация

- `PublicReadingLayout` используется маршрутами курса и конспекта: одна публичная шапка,
  подвал, стили чтения и переключатель темы.
- `PublicReadingCover` содержит общую обложку с заголовком, рисунком и местом для действий.
  Действия курса остаются только у курса; конспект предлагает перейти к тексту.
- Текст конспекта рендерится на сервере прежним `StudyNotesPreview` с `ArticleContentServer`:
  Markdown, формулы, таблицы и раскрываемая самопроверка сохраняются.
- Канонический адрес сохранён. Добавлены метаданные для ссылки, состояния недоступного
  конспекта и ошибки API с повтором. Запрос остаётся `no-store`.

## Проверки

- 11 тестов: публичные страницы курса и конспекта, оглавление; содержимое, формулы,
  безопасный Markdown, канонический адрес, 404/422 и ошибка 503.
- TypeScript, ESLint, Prettier и `git diff --check` прошли.
- В локальном браузере проверены 320, 390, 1440 и 3840 px, обе темы, отсутствие
  горизонтального переполнения, переход к тексту с фокусом и раскрытие ответа.
- В курсе «Основы Python» проверено переключение статьи через оглавление после выделения
  общего компонента. Для неверного ID конспекта показано состояние «Конспект недоступен».
- Скриншот `review/desktop.png` хранится локально и исключён из Git.

Общая сборка столкнулась с параллельной записью в `.next` из другого чата; для повторной
проверки подготовлен отдельный снимок в `.private/public-note-build-20261118/web`.
Production-сборка этого снимка успешно завершена; статические ресурсы и шрифты подключены
из проекта. HTTP-проверка: опубликованный конспект — 200, неизвестный ID — 404.

Коммит, push и деплой в этой задаче не выполнялись.
