# Тариф и подписка: три концепта

Этап выбора композиции, 18 ноября 2026. Производственная страница и платёжная логика не изменены.

- [А — тарифы строками](a.png): вертикальное чтение, цена слева, возможности в центре, действие справа. Самая спокойная композиция; на телефоне строки складываются в последовательные блоки.
- [Б — сравнение возможностей](b.png): одинаковые параметры в общих строках. Удобнее всего сравнивать квоты Plus и Pro; при реализации на телефоне нужна последовательная подача без обязательной горизонтальной прокрутки.
- [В — три карточки](c.png): каждый тариф читается отдельно, небольшие утверждённые рисунки поддерживают стиль кабинета. Привычный выбор; общие возможности повторяются.

**Выбран вариант В** — три карточки. Выбор пользователя от 18 ноября 2026. Следующий этап: [демонстрация движения](../motion/README.md).

Все изображения — 1440 × 1240. Один и тот же Free и одна история: два отменённых годовых Pro по 9 999 ₽, возвращённый годовой Plus за 2 499 ₽ от 26.10.2026. Это наблюдённое состояние локального технического аккаунта. Имя и реферальный код заменены демонстрационными. Нулевой расход, остаток и будущая дата окончания не выдуманы.

## Неизменный контракт

| Параметр | Free | Plus | Pro |
| --- | --- | --- | --- |
| Месяц | Бесплатно | 299 ₽ | 999 ₽ |
| Год | Бесплатно | 2 499 ₽ | 9 999 ₽ |
| Курсы / наборы | 10 / 20 | Без лимита | Без лимита |
| Записи через MCP в неделю | 500 | Без лимита | Без лимита |
| Расшифровка в неделю | Нет | 300 минут | 1 500 минут |
| Генерация в неделю | Нет | 500 000 токенов | 2 500 000 токенов |
| Закрытые материалы | Нет | Да | Да |
| Отчёты | Базовые, 1 класс | Полные и XLSX | Полные и XLSX |

Обучение, повторения и доступ к созданному сохраняются. Число 500 ответов — мягкий антиабуз-сигнал, не пользовательская квота обучения. Дополнительные реальные границы каталога также не меняются: 30 / 200 / 500 учеников в классе; 3 / без лимита / без лимита активных заданий; TTS 5 000 / 150 000 / 150 000 символов в месяц. Они не входят в краткую витрину текущей BillingPage и не подменяются новыми значениями.

Период по умолчанию — год. Оплата разовая через существующий redirect в ЮKassa. Нет автопродления, пробного периода, сохранённой карты или переключателя регулярных списаний. Для текущего платного тарифа кнопка остаётся недоступной, как сейчас: отдельное действие «Продлить» не добавлено.

Промокод передаётся в checkout. Отдельного API предварительной проверки нет: макеты не показывают кнопку «Применить» или ложное подтверждение скидки. Процент влияет на сумму при создании платежа; бонусные дни начисляются после успешной оплаты. Реферальная ссылка имеет вид `/register?ref=…`; бонус обоим — 30 дней Plus после первой успешной оплаты приглашённого.

Entitlements разрешает права в порядке персональное переопределение → действующая подписка → Free и сохраняет снимок версии оплаченного тарифа. API уже возвращает usage, remaining и resets_at, но BillingPage этот эндпоинт пока не использует. Счётчики расхода не добавлены в концепты как якобы существующая функция.

## Состояния для реализации выбранного варианта

| Состояние | Поведение |
| --- | --- |
| Free без истории | Текущий Free; история не отображается, как сейчас |
| Активный Plus / Pro | В верхней панели реальное название и дата окончания; «Разовая оплата, автосписаний нет»; соответствующий тариф помечен текущим |
| Окончание периода / полный возврат | Показывается фактически разрешённый тариф; материалы и обучение остаются доступны |
| Загрузка каталога | Скелетон сохраняет геометрию выбранной композиции |
| Ошибка каталога | Сообщение вместо тарифов; нельзя показывать выдуманные актуальные цены |
| Ошибка обзора | Отдельная ошибка текущего тарифа и истории; не выдавать ошибку загрузки за Free |
| Создание checkout | Индикатор на выбранном действии, защита от повторного нажатия; существующие plan_code, interval, request_key, promo_code сохраняются |
| Ошибка checkout / промокода | Сообщение рядом с оформлением, значение кода и период сохраняются |
| Возврат из ЮKassa | Не считать `?payment=return` доказательством успеха; статус берётся с сервера |
| pending | «Ожидает оплаты» с текстовым обозначением ожидания |
| succeeded | «Оплачен» |
| canceled | «Отменён» |
| refunded | «Возвращён» |
| Ссылка скопирована | Подтверждение рядом с кнопкой; ошибка буфера обмена не теряется |

Существующая страница не имеет отдельного сообщения об ошибке overview, не обрабатывает ошибку clipboard и не выделяет возврат из платёжной системы. Это замечания для следующего этапа, а не уже выполненные изменения. Право доступа берётся с сервера; макет не меняет Entitlements или обработку вебхуков.

В реализации нужны светлая и тёмная темы, цели от 44 px, полные названия, видимый фокус, клавиатура, reduced motion, стабильная геометрия при смене периода. Сначала пользователь выбирает А/Б/В, затем демонстрируется движение, после согласования выполняются вёрстка, подключение движения и проверка действий.

## Артефакты и проверка

`index.html` — изолированный статичный источник изображений, не новая страница приложения. Параметры `?v=a`, `?v=b`, `?v=c` выбирают композицию. В макете работает только смена периода. Он не вызывает API, не создаёт платежей и не копирует демонстрационную ссылку. Полноценные действия подключаются только на этапе реализации.

Из корня репозитория можно запустить `python3 -m http.server 8768 --bind 127.0.0.1` и открыть `/docs/app-redesign/billing/concepts/index.html?v=a`.

Проверены живое переключение год/месяц без checkout, наличие текущих функций страницы, загрузка ассетов всех концептов, читаемость PNG, сохранение цен 299/999 и 2 499/9 999 при смене периода. Изображения получены браузерными снимками HTML, без imagegen. Производственные тесты не запускались: код приложения не изменён.
