# Движение варианта В

18 ноября 2026 пользователь выбрал три карточки с небольшими чернильными рисунками.
Это изолированное превью следующего этапа; BillingPage и серверная логика не изменены.

- [Интерактивное превью](preview.html) — автономный HTML, открывается и без сервера.
- [Запись GIF](preview.gif), [MP4](preview.mp4), [общий вид](preview.png).

## Поведение

- **Период оплаты:** синяя подложка перемещается за 180 мс. Значение цены меняется сразу;
  новый текст появляется за 150 мс с вертикальным смещением 3 px. Нет анимированного
  пересчёта цифр или задержки перед действием. Быстрое повторное переключение отменяет
  предыдущую анимацию цены. Год остаётся начальным выбором.
- **Выбор Plus:** наведение на кнопку или видимый клавиатурный фокус слегка приподнимает
  блокнот на 3 px и поворачивает на −2°. Под названием тарифа появляется тонкая синяя
  линия. Продолжительность — 220 мс, без пружины. При уходе мыши и фокуса рисунок возвращается.
- **Выбор Pro:** та же логика с подъёмом стопки книг на 2 px и поворотом на 1°.
  Сама карточка не прыгает и не становится целиком кликабельной. Free остаётся спокойным:
  у текущего бесплатного тарифа нет действия покупки.
- **Промокод:** кнопка «Есть промокод» раскрывает небольшой блок с полем за 160 мс,
  без перестройки карточек. Фокус переходит в поле. Escape закрывает блок и возвращает
  фокус на кнопку; нажатие вне блока закрывает его. Введённый текст сохраняется.
- **Сокращённое движение:** системная настройка имеет приоритет. Подложка и рисунки не
  перемещаются, цена обновляется мгновенно, фокус и выбранный период остаются различимыми.
  У демонстрации есть дополнительный ручной переключатель; он не меняет настройки кабинета.

Главный акцент — ясная смена оплачиваемого периода. Рисунки откликаются только на действие
выбора тарифа. Нет появления секций при прокрутке, автоматических циклов или задержки перехода
к оплате. В рабочем интерфейсе касание должно сразу запускать существующий checkout.

Промокод сохранён в той же зоне, что и в концепте В, но поле теперь раскрывается по запросу.
Это единственная небольшая композиционная корректировка для согласования на этом этапе.
Проверка промокода и скидка до checkout не имитируются.

## Как смотреть

Нажать «Показать движение»: один проход показывает месяц → год → Plus → Pro → промокод.
Во время показа доступна остановка; после завершения можно повторить. Вне показа работают
реальные наведение, клавиатурный фокус, переключение периода и поле кода.

`?theme=dark` открывает тёмную тему; `?reduced=true` отключает пространственное движение.
Переключатели в верхней полосе относятся только к демонстрации и не попадут в BillingPage.
Навигация здесь иллюстративная, реальные переходы кабинета не подключены.
Кнопки покупки показывают пояснение о демонстрации, не создавая платежей. Копирование
демонстрационного реферального кода тоже не меняет буфер обмена.

Все цены, квоты и история совпадают с выбранным [концептом В](../concepts/c.png).
Автопродления, пробного периода и сохранённой карты нет. Активные подписки и остальные
платёжные состояния реализуются по [зафиксированному контракту](../concepts/README.md).

## Проверка

Headless Chromium: цены 299/999 при месяце, начальные 2 499/9 999 при годе, загрузка
всех изображений, раскрытие поля и возврат фокуса через Escape, Tab/Shift+Tab на покупке,
остановка и повтор демонстрации, ручной и системный reduced motion. При системном
сокращении движения после смены периода число активных анимаций — 0.

На ширинах 320, 390, 768, 1024 и 1440 px в светлой и тёмной темах нет горизонтального
переполнения, кнопки периода имеют высоту 44 px. Визуально просмотрены десктоп и тёмный
мобильный экран 320 px. Ошибок JavaScript не обнаружено. GIF и MP4 записаны из браузера;
повтор GIF нужен только для просмотра, само взаимодействие проигрывается один раз.

Знак и три рисунка встроены из существующих ассетов без изменения геометрии и цвета.
На тёмной поверхности маленькие рисунки сохраняют светлую бумагу. Новых зависимостей нет;
эффекты используют CSS transform/opacity и Web Animations API.

и проверка настоящих действий, данных, ошибок и переходов без реальных покупок.
