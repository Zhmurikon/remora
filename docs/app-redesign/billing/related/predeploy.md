## Препятствия общего выпуска

1. Ветка и рабочее дерево продолжают меняться из нескольких задач. Тарифные изменения ещё не закоммичены. `deploy/push.sh` синхронизирует через rsync всё рабочее дерево, включая незакоммиченные файлы, а не конкретный Git-снимок. Нельзя запускать его из этого смешанного каталога до фиксации состава релиза; безопасный источник — отдельный checkout выбранного коммита.
2. Общая сборка кабинета остановилась на `ClassesPage.tsx`: `ClassIcon name="info"` отсутствует в допустимых именах `ClassIcon`. В ходе тестов также отсутствовал `features/classes/class-screens.css`, из-за чего падала загрузка всего кабинета; позднее другой задачей файл создан. Эти изменения не входят в тарифный срез и не исправлялись здесь.
3. Полный прогон кабинета с двумя workers: 304 теста прошли, один тест упал и один файл тестов не загрузился. Файл — ClassesPage из пункта 2. Тест эталонного решения «Корреляция Пирсона» превышает тайм-аут 5000 ms; отдельный повтор с одним worker также не прошёл. Пока причина не устранена или не квалифицирована владельцем раздела Python, общий прогон нельзя считать зелёным.

После завершения соседних задач нужно выбрать единый коммит, повторить общий прогон и сборку этого неизменяемого снимка. Успех тарифного среза не заменяет проверку всего релиза.
