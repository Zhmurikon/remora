# Достижения: три концепта

Этап 1, 18 ноября 2026 года. Вариант ещё не выбран; производственный интерфейс не изменён.

## Варианты

- [А — карточки по категориям](a.png). Последовательная коллекция с переходами к разделам. Наглядная, но длинная; нижние категории продолжаются за пределами изображения.
- [Б — компактный журнал](b.png). Все 20 достижений в двух колонках, сгруппированных по категориям. Рекомендуемый вариант: полный обзор, меньше рамок, короткие описания целиком.
- [В — навигатор категорий](c.png). Пять категорий слева, просторный список выбранной категории справа. На изображении открыто «Обучение»; остальные достижения доступны при переключении категории.

Все изображения созданы встроенным image_gen. Точные запросы находятся в `a.prompt.txt`, `b.prompt.txt`, `c.prompt.txt` и встроены в PNG. Это концепты композиции, а не скриншоты готовой реализации. При реализации знак подключается из существующего `apps/web/public/lecture-demo/remora-icon.png`, как в текущем AppLayout, без перерисовки. Случайные различия генерации в толщине линий и размерах навигации не являются предложением менять общий каркас.

## Состояния и действия, которые нужно сохранить

| Состояние | Текущее поведение и требование к реализации |
| --- | --- |
| Загрузка | Skeleton общей статистики и списка; `aria-busy`, без пульсации при reduced motion. |
| Ошибка | «Не удалось загрузить достижения», пояснение и рабочая кнопка «Повторить» через refetch. |
| Нулевой прогресс | Число `0 из target`, пустая полоса, читаемые название и условие. Это не отключённый элемент и не тарифная блокировка. |
| Частичный прогресс | Точные `progress` и `target`, доступная полоса прогресса. |
| Получено | Текст «Получено» и компактная отметка, не только цвет. Дата есть в API, но текущая страница её не показывает. |
| Новое достижение | Существующее глобальное уведомление: первое достижение, число остальных, закрытие и «Посмотреть коллекцию». Оба действия отмечают показанное через acknowledge; переход ведёт в коллекцию. В локальном снимке новых уведомлений не было, поведение изучено по коду. |
| Пустой каталог / 0 полученных / все получены | Отдельно проверить при реализации; общий процент не делит на ноль, категории формируются из ответа API. |

Не добавлять «забрать награду», вымышленные бонусы, рейтинг или обязательный выбор цели. Текущая страница не имеет действий над отдельным достижением. Сохраняются глобальная навигация, тема, выход, уведомление и повтор запроса. Навигация по категориям А/В — дополнительное удобство, не изменение условий получения.

## Следующие этапы после выбора

1. Продемонстрировать короткое движение состояния/категории; без декоративного появления всей страницы. Сокращённое движение — мгновенное переключение.
2. Сверстать выбранный вариант в существующей оболочке, подключить движение и данные без изменения сервиса достижений.
3. Проверить реальные действия, переходы, ошибки, новую награду, обе темы и адаптивность. В А сетка становится одноколоночной; в Б две колонки переходят в последовательный список; в В категории переходят над содержимым. Полные названия, клавиатура, видимый фокус и цели от 44px обязательны.

Ни вёрстка, ни анимация, ни проверки реализованного экрана на этом этапе не заявлены завершёнными.
