# Достижения в публичном профиле

По прямому разрешению владельца обновлён блок `/avtor/[username]#author-stats`. Пять существующих показателей собраны в компактную полосу, текстовые значки заменены иллюстрированными карточками. Шрифт заголовка — Georgia 30 px, названия наград — 16 px, подписи и статусы — 14 px. Тонкие синие границы, бумажные поверхности и цвета обеих тем взяты из существующих `--rm-lecture-*`.

Публичный API возвращает только полученные авторские награды. Блок показывает ровно этот список; личная коллекция из 20 достижений, закрытые награды и процент до полной коллекции не добавляются. Правила выдачи, статистика, доступность профиля, метаданные и публичные курсы не изменены. При отсутствии наград остаются статистика и сообщение «У автора пока нет наград». На широком экране до четырёх карточек в ряд, на узких две или одна.

Использована та же общая иллюстрация, что в кабинете: без создания новых картинок, с пустым alt и явным текстом «Получено». Публичная копия лежит в `apps/web/public/achievements/`, Next Image отдаёт уменьшенные версии. Изображения не передают смысл без текста, карточки не изображают кнопки. Остальная страница автора пока сохраняет прежнее оформление.

Проверены:

- Реальный локальный профиль `yuriy`: две награды («Первый курс», «Сто карточек»), пять показателей; данные сверены с публичным API.
- Обе темы при 320, 390, 768, 1024, 1280, 1440 и 1920 px: без переполнения при обычном размере текста, иллюстрации загружаются.
- При тексте 200% на 320 px новый блок помещается. В прежней навигации и карточках курсов обнаружено переполнение — остаётся в задаче полного обновления публичного профиля.
- Три теста страницы: статистика и пустые награды, две полученные иллюстрированные награды из публичного ответа, canonical/Open Graph; ссылки на курсы сохранены.
- TypeScript публичного сайта, ESLint целевых файлов и Prettier прошли.
