# Три концепта уведомления о достижении

Подготовлены три варианта; владелец выбрал А. [Компактное немодальное уведомление реализовано](../popup-implementation/README.md). Ниже сохранены исходные концепты. Существующие действия сохранены: закрыть уведомление и перейти в коллекцию. Все варианты используют одну общую иллюстрацию, бумажно-синюю палитру, Georgia для заголовка, подписи 14 px, цели нажатия от 44 px.

- **А — Компактное уведомление.** Небольшой рисунок слева, название и условие справа, кнопка снизу. Ширина 420 px, положение справа внизу. Рекомендуемый вариант: меньше перекрывает учебный экран. [В контексте](a.png), [крупно](a-detail.png), [HTML](a.html).
- **Б — Открытка.** Крупный рисунок над названием, кремовая бумага и центральная композиция. Ширина 360 px, положение справа внизу. Более торжественный вариант, занимает больше высоты. [В контексте](b.png), [крупно](b-detail.png), [HTML](b.html).
- **В — Стопка наград.** Разложенные карточки слева и информация справа, широкая панель по центру снизу. Ширина 660 px, на мобильном вертикальная компоновка. При одной награде задние карточки скрываются. [В контексте](c.png), [крупно](c-detail.png), [HTML](c.html).

Во всех макетах показан один демонстрационный сценарий: «Первая сотня», «Ответьте на 100 карточек» и «И ещё 2 в вашей коллекции». Это пример оформления, не новые награды пользователя. В HTML есть переключатели одной и трёх наград, закрытие и повторное открытие. Кнопка ведёт в локальную коллекцию; API подтверждения показа макеты не вызывают.

Это немодальные уведомления без затемнения страницы, захвата фокуса и автоматического исчезновения. Клавиатурный фокус видимый, уведомление имеет role=status и aria-live=polite. Производственные очередь, acknowledge, повтор после ошибки и анимация появления должны сохраняться или отдельно проверяться при реализации выбранного варианта.

Изображения — снимки локального браузера. Фоновый экран взят из проверки уже реализованной коллекции; данные профиля в его боковой панели скрыты. Проверены оба количества наград, закрытие и повтор, адрес перехода, светлая/тёмная темы и 320/1440 px без горизонтального переполнения. В статичных макетах анимации нет. [Проверки](checks.json).
