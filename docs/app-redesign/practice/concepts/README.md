# Стартовая страница практики: три концепта

Дата: 18 ноября 2026 года. Этап: выбор композиции. Производственный интерфейс не изменён.

## Варианты

- [А — продолжение](a.png): последняя незавершённая задача, затем прогресс и вход в каталог Python. Рекомендуемый вариант при одном тренажёре: главное действие видно сразу, каталог остаётся самостоятельным входом.
- [Б — обзор тем](b.png): состав Python слева, продолжение и прогресс справа. Помогает оценить содержание тренажёра до начала. Четыре группы — обзор существующих тем, не новые тренажёры и не заблокированные ступени.
- [В — недавние задачи](c.png): компактная сводка Python и список последних задач. Удобнее для возвращения к нескольким решениям; при первом посещении этот список отсутствует.

Во всех вариантах одинаковый демонстрационный сценарий: решены первые три задачи, «Чётное число» находится в работе; 3 из 46, округлённо 7%. Это не статистика аккаунта пользователя. Полные названия и короткие описания сохраняются.

Изображения подготовлены встроенным image_gen; [промпты](prompts.md) сохранены. Все три изображения имеют одинаковое разрешение 1487 × 1058. Это растровые концепты, точные размеры каркаса при реализации берутся из AppLayout: rail 260 px. Знак в реализации подключается напрямую из существующего файла, а не вырезается из макета.

## Что есть в текущем коде

Проверены `apps/app/src/pages/PracticePage.tsx`, его тесты, маршруты в `App.tsx`, `AppLayout.tsx`, каталог задач, локальное хранение и синхронизация в `features/practice/`.

| Экран | Реальные функции |
| --- | --- |
| `/app/practice` | Статический заголовок, описание и одна ссылка-карточка Python. Своего запроса прогресса сейчас нет. |
| `/app/practice/python` | 46 задач, общий прогресс, фильтры темы и статуса, пустая выдача со сбросом фильтров, состояния синхронизации и офлайн-очереди. Удаление прогресса с подтверждением и обработкой ошибки находится внизу каталога. |
| `/app/practice/python/:taskSlug` | Условие, примеры, встроенные CSV для соответствующих задач, раскрываемая подсказка, редактор, запуск и проверка, остановка, вывод и ошибки, графики, черновик, статус, разбор после успеха и переход к следующей задаче. Неизвестный slug обрабатывается отдельным состоянием. |

Каталог: 18 базовых задач, 8 по NumPy, 12 по pandas, 8 по SciPy и matplotlib. Состояния задач: `not_started`, `in_progress`, `solved`. Прогресс содержит черновик, число попыток и `updatedAt`; лучшая отметка и последний черновик синхронизируются с сервером. Исполнитель Python загружается на экране задачи, не на стартовой странице.

Сведения о функциях и состояниях сверены по коду и существующим тестовым сценариям. Защищённые локальные страницы в отдельной браузерной сессии перенаправили на вход; полный живой проход авторизованного сценария в этом этапе не выполнен. Визуальный ориентир сверялся по сохранённым превью работающей вёрстки `materials/concepts/a-preview.png`, `sets/combined-preview.png` и актуальным CSS `dashboard.css`, `materials.css`. Новых проверок рантайма эти изображения не подтверждают.

## Переходы и состояния выбранной реализации

- «Все 46 задач» открывает существующий `/app/practice/python`; все фильтры и сброс прогресса остаются там.
- «Продолжить задачу» открывает slug наиболее недавно изменённой незавершённой задачи по `updatedAt`. Поле отражает изменение, а не просмотр; обещать «последнюю открытую» задачу нельзя.
- Если незавершённых задач нет, предлагать первую нерешённую по порядку каталога. При нулевом прогрессе показывать «Начать практику» и «Приветствие по имени», без фиктивной истории и надписи «Продолжить».
- Если решены все 46, показывать завершение и действие «Повторить задачи», ведущее в каталог. Не сбрасывать данные автоматически.
- Для В недавние задачи определять по `updatedAt`, исключая нетронутые начальные записи. Решённые задачи можно открыть повторно.
- Для Б групповой прогресс вычислять из тех же статусов. Строки тем на концепте информационные: существующий каталог не читает фильтр из URL. Кликабельные темы потребуют отдельно поддержать передачу фильтра.
- Загрузку и фоновую синхронизацию отделить от состояния «не начато». Доступный локальный прогресс не скрывать, а нули до окончания запроса не выдавать за серверный результат.
- При ошибке сети сохранять доступ к тренажёру и локальным черновикам, показывать «Офлайн» и размер очереди. Не писать «Сохранено в аккаунте», пока синхронизация не завершилась успешно.
- Связи с заданиями классов и произвольными курсами не добавлять: на этих маршрутах такого контракта нет.

## Визуальные ограничения для следующих этапов

Общий каркас и порядок навигации сохраняются. Ориентир — светлая бумага, синие чернила, тонкие границы, спокойные заголовки и небольшая зарисовка. Исторические бирюзовые токены и старый знак из design.md не переносить в новую поверхность. В рисунках не показывать готовое решение задачи.

На телефоне: общая мобильная шапка кабинета; порядок «название → продолжить → прогресс → каталог» для А, правая карточка выше обзора в Б, строки задач складываются в В. Полные названия переносятся, кнопки имеют цель от 44 px. Проверить 320, 390, 768 и 1440 px, обе темы, клавиатуру, focus-visible, состояния загрузки/ошибки и reduced motion.

Порядок продолжения: выбор А/Б/В → демонстрация движения → вёрстка → подключение движения → проверка действий и переходов. В этом этапе выполнены только анализ и три растровых концепта.
