# Вложенные страницы практики

18 ноября 2026 года. По просьбе пользователя подготовлен один макет каждого типа страницы,
в выбранном ранее стиле А. Применён встроенный image_gen, референс — работающая стартовая
страница. Макеты продолжают согласованное направление; отдельного выбора из трёх нет.

- [Каталог Python](catalog.png): прогресс и продолжение, фильтры темы/статуса, компактный
  список с полными названиями, описаниями, сложностью и состоянием. Из 46 задач на изображении
  показаны первые шесть; при реализации список продолжается без пагинации.
- [Экран задачи](task.png): условие и примеры слева, редактор и результаты справа.
  Основное действие — проверка решения, запуск остаётся рядом. Сброс кода — компактная
  кнопка с подсказкой. Сохраняются остановка, горячие клавиши, черновик и попытки.

Покрытие маршрутов: `/app/practice/python` и `/app/practice/python/:taskSlug` для всех
46 задач. У неизвестного slug — сообщение и возврат в каталог в том же бумажном каркасе.
Сама стартовая страница не перестраивается.

Варианты содержимого рабочего экрана:

- Обычный ввод/вывод: таблица примеров и редактируемый stdin.
- Функции: «Вызов / Результат», вместо stdin — пояснение об автопроверке.
- pandas/CSV: раскрываемые встроенные файлы под примерами, без новых загрузок.
- SciPy/matplotlib: библиотеки в метаданных, графики в области результатов с подписями.
- Результаты: ожидание, загрузка Python, выполнение, остановка, таймаут, ошибка Python,
  несовпавший ответ, успешная проверка, сокращённый вывод и время выполнения.
- После успеха: раскрываемый разбор, эталон и следующая задача; после последней — каталог.
- Каталог: загрузка/синхронизация, офлайн-очередь, пустая фильтрация со сбросом фильтров.
  Удаление всего прогресса перенесено в раскрываемый раздел внизу; подтверждение сохраняется.

Мобильная компоновка: условие → примеры/файлы/подсказка → код → запуск/проверка → результат.
Никакие элементы не исчезают из-за ширины экрана. Текст переносится полностью, код и CSV
имеют собственную прокрутку. Цвета — действующие токены двух тем, цели от 44 px, видимый
фокус, сокращённое движение. Движение ограничено подсветкой ссылок и кнопок; рисунки
не отвлекают во время набора кода.

Данные на макетах демонстрационные: 3 решены, 1 в работе, 7%. Иллюстративный комментарий
в коде не меняет стартовый код настоящей задачи. При вёрстке названия задач набираются
с умеренным весом 500, независимо от веса букв в растре.
