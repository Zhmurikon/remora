# Движение варианта А

18 ноября 2026 года пользователь выбрал концепт А и запросил демонстрацию движения.
Это отдельное превью; `PracticePage` и остальные производственные компоненты не изменены.

- [Интерактивное превью](preview.html) — автономный HTML с встроенными изображениями, открывается без сервера и зависимостей.
- [Короткая запись GIF](preview.gif) и [MP4](preview.mp4) — покой, наведение, удержание, уход указателя.
- [Общий вид](preview.png) — композиция в каркасе кабинета.

## Поведение

При наведении мыши на «Продолжить задачу», на сам блокнот или видимом клавиатурном фокусе блокнот
поднимается на 3 px и поворачивается на −1° за 220 мс. Стрелка сдвигается на 3 px
за 180 мс. Три чернильные строки проявляются через transform/opacity за 200 мс
с задержками 0, 85 и 170 мс, затем появляется маленькая отметка с задержкой 270 мс.
Она декоративная: задача остаётся «В работе», прогресс не меняется, решение не показано.
После ухода указателя и фокуса рисунок возвращается за 140 мс, без зацикливания.

На телефоне касание запускает короткий показ; отдельная кнопка «Показать движение»
доступна всем способам ввода. В производственном интерфейсе касание должно сразу
открывать задачу, без ожидания анимации. Здесь основной элемент намеренно не навигирует,
чтобы можно было рассмотреть эффект. При reduced motion рисунок и стрелка неподвижны,
меняется только цвет кнопки; видимый фокус сохраняется.

Для фиксации состояний: `?state=open`, `?state=open&reduced=true`, `?theme=dark`.
В верхней панели есть переключение темы и ручное сокращение движения; системная
настройка `prefers-reduced-motion` имеет приоритет. Встроенные переключатели относятся
только к демонстрации и не записывают настройки кабинета.

## Проверено

Headless Chromium: исходное и активное состояния, уход указателя, быстрое повторное
наведение, Tab/Shift+Tab, повтор показа, касание с последующим возвратом, состояния
по URL, системное и ручное сокращение движения. На ширинах 320, 390, 768 и 1440 px
в обеих темах нет горизонтального переполнения; основная цель нажатия от 44 px.
Ошибок JavaScript нет. Вручную просмотрены десктопное активное состояние и тёмная
мобильная версия 320 px. Растровый блокнот встроен без цветовых фильтров.

Запись собрана из кадров настоящих CSS-переходов, зафиксированных через Web Animations
API при 20 кадрах/с; GIF повторяет запись для просмотра, само взаимодействие не циклическое.

## Иллюстрация

Блокнот подготовлен встроенным image_gen по утверждённому [концепту А](../concepts/a.png).
Официальный знак встроен напрямую из `apps/web/public/lecture-demo/remora-icon.png`.
Прозрачный блокнот экспортирован в WebP 560 × 560 и встроен в HTML. Промпт:

> Extract and recreate ONLY the small blue ballpoint spiral notepad illustration from the upper-right of this approved UI reference as a clean reusable illustration on TRUE transparent background. Preserve the same blue pen hatch drawing, portrait top spiral notebook in three-quarter view, leaning slightly back, pages and delicate ink shadow underneath. Enlarge to fill a square canvas with 12% transparent padding. The page must be ENTIRELY BLANK: remove the little lines and square on the paper. The white paper itself is opaque white, background surrounding the notebook transparent. No text, letters, code, checkmarks, interface, logo or other objects. This will be overlaid with animated vector pen marks. Position the front page near vertices (35%,25%), (77%,30%), (68%,78%), (20%,72%).

Движение согласовано с дополнением: запускать его также при наведении на блокнот.
