# Практика: реализация варианта А

18 ноября 2026 года. Локальная страница: `http://localhost:3000/app/practice`.

Стартовая страница перенесена в `PracticeStartPage.tsx`, экспорт `PracticePage` и все
существующие маршруты сохранены. В `AppLayout` добавлена только принадлежность
`/practice` к бумажному каркасу. Использованы действующие токены обеих тем и официальный
знак общего каркаса; блокнот вынесен из согласованного превью в отдельный WebP.

Продолжение выбирает последний незавершённый черновик по `updatedAt`, иначе первую
нерешённую задачу. После решения всех задач предлагается каталог без удаления прогресса.
Синхронизация использует существующий контракт через TanStack Query; локальные данные
не скрываются при обновлении, до первой загрузки нулевой прогресс не показывается.
При ошибке доступны локальный прогресс, размер очереди и повтор синхронизации.
Обновление выполняется при возврате на страницу, фокусе окна, восстановлении сети
и изменении локального хранилища в другой вкладке.

Блокнот реагирует на наведение и на него самого, и на основную ссылку; клавиатурный
фокус основной ссылки запускает тот же эффект. Неподвижная область наведения отделена
от движущегося рисунка, чтобы край иллюстрации не вызывал мерцания. При сокращённом
движении рисунок и стрелка статичны. На телефоне основная ссылка сразу открывает задачу.

Во время живого прогона найдено необработанное отклонение `fetch` в существующей
синхронизации каталога при потере сети. `flushPythonProgress` и `syncPythonProgress`
теперь возвращают штатный неуспешный результат, сохраняя черновики и очередь.
Добавлен тест сетевого исключения с повторной успешной отправкой.

## Проверки

- 30 тестов страниц практики, локального прогресса и синхронизации.
- ESLint для изменённых TypeScript-файлов и отдельная строгая проверка типов этих файлов
  с их зависимостями, на основе tsconfig приложения.
- Production-сборка Vite. Полный `pnpm --filter @remora/app typecheck` на момент проверки
  блокировался параллельной правкой `SettingsPage.tsx`: обращением к `parentElement`
  у `EventTarget`. Чужой код в этой задаче не изменялся.
- Живой локальный API с временным аккаунтом: начальное состояние, вход в первую задачу,
  каталог, фильтры и пустая выдача, сброс фильтров, серверный прогресс 3/46,
  продолжение четвёртой задачи с сохранённым кодом, возврат назад, переход во все задачи,
  ошибка API и повтор, отсутствие сети и восстановление, 46/46 и повтор через каталог.
- Наведение на блокнот, кнопку и переход между ними, уход, клавиатурный фокус и reduced motion.
- 320, 390, 768, 1024, 1440 и 1920 px в обеих темах: нет горизонтального переполнения,
  блокнот не перекрывает описание, основная цель нажатия от 44 px.
- Браузерных ошибок в итоговом прогоне нет; временный аккаунт и его прогресс удалены.

В тестовой вкладке отключён WebSocket обновлений Vite, чтобы изменения других чатов
не перезагружали страницу посреди сценария. API-запросы реальные; только проверка
ошибки синхронизации использует временный ответ 503.
