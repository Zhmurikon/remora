# Концепты страницы подборок

18 ноября 2026 года. Эскизы для `/podborki` в направлении «На полях лекции».
Выбран вариант А — папка с материалами. Вёрстка описана в [отчёте](../implementation.md).
Следующий этап — согласование движения.

## Содержание и композиции

На локальной странице и в `apps/web/src/content/collections.ts` опубликована одна
подборка «К первому зачёту». Во всех вариантах использованы её название, описание,
действие «Посмотреть курсы» и существующее предложение создать свои карточки.

- [А. Папка с материалами](a-folder.png). Крупная горизонтальная папка с рисунком
  слева и текстом справа. Подборка занимает основную площадь страницы.
- [Б. Редакционный разворот](b-editorial.png). Вводная колонка слева, иллюстрация
  и описание подборки справа. Композиция рассчитана на подробное знакомство с темой.
- [В. Читательский список](c-index.png). Заголовок по центру, подборка отдельной
  строкой между тонкими линиями. Новые подборки добавляются следующими строками.

## Ориентиры реализации

Общая ширина эскизов 1536 px. Для вёрстки ориентир при 1440 px — Georgia 65/64
для H1, 28/33 для H2, вводный абзац 18/27, основной текст 16/25, кнопки 16/22,
метаданные 14/21. На телефоне H1 33/34, H2 24/28, текст 16/25.
Масштабирование сверяется со шкалой `seo/audit/landing/09-typography.md`.
Изображения концептуальные, точные метрики текста задаются при вёрстке.

Фирменный знак при вёрстке берётся из утверждённых бренд-ассетов. В эскизах
шапка показана текстовым названием. Эскизы исследуют содержимое страницы;
существующая общая навигация учитывается при встраивании.

## Генерация

Использован встроенный imagegen. Полные запросы сохранены в `prompts.json`.
Три отдельных запроса задают одинаковый текст, палитру и типографику,
различаясь композицией. PNG хранятся локально и исключены из Git правилами проекта.
