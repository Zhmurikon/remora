# Результаты учебной сессии

Область: SessionSummary, его локальный CSS и тесты. Props и экспорт Diff сохраняются. Режим Operate/Read. Продолжение существующего кабинета, без нового визуального языка.

Визуальная опора: реальные материалы, набор и чтение курса на локальном стенде. Текущая реализация кабинета использует бумажную поверхность, антикву заголовков, синие действия, тонкие разделители. Наследовать токены dashboard-shell, а не старые упоминания бирюзового варианта.

Первый экран: ссылка к источнику, спокойный заголовок без эмодзи, краткое объяснение, три фактических счётчика (все ответы, верно с процентом, ошибки), имеющийся срок следующего повтора, действия. Ни успеха, ни процента для нуля ответов не обещать.

Разбор: открытый последовательный список. Вопрос, «Ваш ответ», «Правильный ответ». Две колонки на широком экране и последовательные блоки на узком. Визуальная подпись и волнистое подчёркивание дополняют цвет ошибки. Поддержать Markdown, изображения, code/latex, обратное направление и диктант. Не добавлять анимацию статичному итогу.

Контракт: onRepeatMistakes отображается только когда передан и есть ошибки. Страницы сейчас этот callback не передают; соседний чат подтвердил, что его подключение требует отдельного среза жизненного цикла. Нельзя называть обычный restart повтором ошибок. Статистика и очередь не меняются.

Скриншоты desktop-light/dark и mobile-light/dark — реальный SessionSummary на изолированном локальном Vite fixture с явно тестовыми данными. zero-mobile/success-mobile — крайние состояния. Изображения fixture — простая синтетическая диаграмма, не продуктовый ассет. Референсы reference-materials/reference-course — настоящие маршруты временного аккаунта. Продуктовые данные пользователя не менялись.
