# Режимы обучения: локальный редизайн

Проверка 18 ноября 2026 года. Локальный стенд `http://localhost:3000`, отдельный временный аккаунт и его материалы. Данные владельца не изменялись; сервер и публикация не затрагивались.

## Что изменилось

- «Заучивание», «Карточки», «Письмо» и «На слух» используют общую учебную колонку до 864 px. Заголовки, бумажные поверхности и синие действия продолжают актуальные страницы набора и курса. Цвета взяты из существующих токенов обеих тем.
- Вопрос отделён от ввода и управления; подсказки в заучивании и письме раскрываются по запросу. Прогресс показывает пройденное и остаток. Горячие клавиши подписаны рядом с действиями.
- Состояния загрузки, пустой очереди, ошибки запроса и недоступной озвучки получили объяснение и доступный следующий шаг. У ошибки озвучки отдельной карточки есть повтор и переход к письму.
- Письмо и аудирование удерживают исходную карточку на экране обратной связи. Раньше `answer()` сдвигал очередь сразу, поэтому правильный ответ мог относиться к следующему вопросу. Ответ по-прежнему записывается немедленно; блокируется только повторная отправка, пока показан результат.
- Таймеры переходов отменяются при уходе. При явном завершении заучивания уже проверенный ответ записывается один раз до финализации. При повторном запуске сбрасывается локальное состояние вопроса.
- В карточках Enter и пробел не перехватывают собственное действие сфокусированной кнопки. Стрелки продолжают работать после переворота. Смена флажка расписания сохраняет остальные параметры адреса, включая порядок карточек.
- Результат обучения курса возвращает в конкретный курс. Для папки используется существующая страница `/sets/manage`: навигатор материалов не поддерживает прямой выбор папки через URL.
- Самостоятельный `TestPage` получил внешнюю поверхность `study-workspace`. Встроенный квиз урока выводится без неё; общие `lesson-quiz.css` и `LessonQuizControls` не менялись.

Общий `AppLayout` подключён к учебным маршрутам основным чатом. `SessionSummary` и его экспорт `Diff` изменены соседним чатом; публичные контракты сохранены. Планировщик, нормализация, API и биллинг в этом срезе не менялись.

Браузерные сценарии: [основные](browser-scenarios.json), [состояния и восстановление](browser-states.json), [автопоказ и расписание](browser-flashcards.json), [обрыв сети](browser-offline.json), [измерения вёрстки](layout-check.json).

Для состояний, которые локальная инфраструктура не предоставляет, использовались точечные ответы Playwright: WAV для плеера, пустая очередь, отказ проверки TTS и медиа-карточки. Эти подмены не записывались в БД и не подменяют живую проверку внешнего синтеза речи.

При проверке полного сетевого отказа обнаружено исключение `fetch` в общей очереди: ответы оставались в localStorage, статус застревал на отправке. Основной чат исправил обработку исключения отдельно от этого среза. Финальный браузерный прогон проверяет реальный `network abort`, сообщение «Нет связи» и очистку очереди после восстановления и кнопки повтора.

## Ограничения

Живой внешний синтез речи на локальном стенде выключен. Проигрывание и интерфейс проверены с WAV, полный внешний сценарий остаётся отдельной проверкой после подключения сервиса. Повтор только ошибочных карточек через `onRepeatMistakes` требует отдельного согласованного жизненного цикла сессии и остаётся в TODO; этот редизайн не меняет существующие правила повторения.

Коммита, push и деплоя в этом чате нет. Общие правки соседних задач не включались в отдельный снимок.
