# ИИ-помощник: экран результата

Дата: 18.11.2026. Выбран Б «Конспект и действия» с панелью ИИ из В. [Реализация](../implementation.md). Ниже сохранено описание исходных концептов.

## Принятые решения

- Главный экран — вариант Б «Материалы и результат».
- В месте сохранения добавляется «Решить позже». Результат сохраняется в задаче независимо от наличия курса.
- После добавления в курс конспект и урок используют один документ: правки должны быть общими.
- Редактирование визуальное, без обязательной работы с Markdown.
- Доработка с ИИ доступна только Pro, с расходом существующей недельной квоты генерации. Лимит источников: Plus 2, Pro 5. При реализации доступ определяется через Entitlements.
- Конспект — основной результат. Карточки можно создавать позже по актуальному тексту.

## Предложения для интерфейса

Чтение по умолчанию, явный вход в редактирование, автоматическое сохранение со статусом. Доработка с ИИ показывает предложение до применения и сохраняет исходный текст в истории версий. Созданные карточки не перезаписываются автоматически после правок конспекта. Это проектируемое поведение, а не заявление о готовности текущей реализации.

## Три композиции

1. [А. Чистое чтение](a-reading.png). Оглавление слева от документа, действия в верхней панели, создание карточек после текста. Источники и ИИ открываются по запросу.
2. [Б. Конспект и действия](b-workspace.png). Документ слева, справа постоянные действия, связь с курсом и источники. Оглавление сворачивается над текстом. Продолжает двухколоночную композицию выбранного экрана создания.
3. [В. Редактор с помощником](c-ai-editor.png). Показана открытая контекстная панель доработки: выделенный фрагмент, запрос, предложение, «Применить» и «Отменить». Панель можно закрыть. Это состояние работы с ИИ, а не обязательный вид при первом открытии документа. Такой механизм можно совместить с А или Б.

Общие данные: «Строение клетки», два источника (аудио и PDF), конспект сохранён, в курс ещё не добавлен, карточки пока не созданы. Поэтому пустой вкладки карточек нет. У демонстрационного пользователя доработка с ИИ доступна.

## Типографика и адаптация

Целевой десктопный холст 1600 × 1100. H1 Georgia 44/50 px, заголовки документа Georgia 28/36 px, основной текст Georgia 18/29 px, интерфейс sans-serif 16/24 px, пояснения 14/21 px. При вёрстке используются общие компоненты и токены ридера; точное поведение проверяется после выбора. На телефоне: H1 30/36 px, текст 17/28 px, оглавление свёрнуто, боковые панели открываются отдельно; колонки не ужимаются в три узких столбца. На 4K ширина строки остаётся ограниченной.

Референс — утверждённый главный экран Б. Логотип не генерировался, в концептах только текстовое название. При вёрстке сохраняется существующий бренд-компонент.
