# ИИ-помощник: главный экран

Дата: 18.11.2026. Статус: выбран вариант Б «Материалы и результат».
Рабочий интерфейс не изменён. [Экран результата](../result-concepts/README.md) согласуется отдельно.

## Согласованная логика

- Название раздела — «ИИ-помощник».
- Студент добавляет аудио, видео, документы или презентации. В одной задаче несколько источников; ссылки пока исключены.
- Основной результат — конспект, затем карточки. Промежуточные этапы выполняет сервис. Расшифровка — отдельная дополнительная цель для записей.
- Выбор результата: конспект, конспект и карточки, карточки; дополнительные настройки свёрнуты.
- Место сохранения: «Решить позже», «В новый курс», «В существующий курс». При выборе «Решить позже» материал сохраняется в задаче и доступен через историю. Это уточнение принято после генерации эскиза Б: на изображении пока два варианта.
- Конспект добавляется одним уроком в новый или существующий курс. Это тот же документ, а не независимая копия. Готовый текст можно редактировать визуально и позже создать по нему карточки.
- Число вложений зависит от тарифа, но значения лимитов ещё не согласованы. Изображения не устанавливают новые квоты.
- История задач вторична по отношению к запуску новой обработки.

## Концепты

- [А. Рабочий лист](a-workbook.png): вся форма на одном экране, сверху вниз от файлов к результату и курсу. Быстрый повторный запуск, все решения видны сразу.
- [Б. Материалы и результат](b-desk.png): слева источники, справа результат и место сохранения. Предпочтительный вариант для ясного разделения входа и результата без дополнительных переходов.
- [В. По шагам](c-steps.png): последовательное раскрытие. Показан второй шаг — выбор результата; источники видны в сводке, выбор курса находится на следующем шаге. Меньше одновременных решений, больше переходов.

Во всех эскизах одни и те же учебные данные: запись о клетке и PDF, результат — конспект, новый курс «Биология клетки». Это демонстрационные данные.

## Визуальные параметры

Референс — фактическая обновлённая оболочка кабинета на скриншоте `../../classes/review/desktop-light.png`, а не прежний бирюзовый интерфейс расшифровок. Белая бумага, синие действия, тонкие границы, синие рисунки ручкой. В эскизах использовано только текстовое название бренда, утверждённый знак не перерисовывался; при вёрстке используется существующий компонент бренда.

Целевой макет 1600 × 1100, фактические растры 1513 × 1039. Шкала для будущей вёрстки: H1 Georgia 44/50 px, заголовки секций sans-serif 22/29 px, текст и элементы формы 16/24 px, пояснения 14/21 px. На телефоне H1 30/36 px, секции 20/26 px, основной текст 16/24 px; глобальная навигация сворачивается, колонки становятся последовательными. На 4K контент ограничивается по ширине, поля растут, текст не масштабируется пропорционально монитору.

## Генерация

Использован встроенный `image_gen`; исходные промпты — [prompts.json](prompts.json). Для А и Б дополнительный проход исправил только подпись «Куда добавить курс» на «Куда сохранить конспект». Все три результата просмотрены. Картинки хранятся локально и игнорируются Git по правилам проекта.
