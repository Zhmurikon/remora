# ИИ-помощник: реализация

18.11.2026. Локальная реализация без публикации на рабочий сервер.

## Согласованные решения

Главный экран — Б «Материалы и результат». Результат — Б «Конспект и действия»
с боковой панелью ИИ из В. Правка по умолчанию относится ко всей статье;
можно выделить однозначный текстовый фрагмент. Место сохранения: решить позже,
новый курс или существующий. Plus — 2 источника, Pro — 5; ИИ-доработка только Pro.

## Что работает

- `/app/transcriptions` открывает форму и историю, а `/app/transcriptions/:id` — задачу.
- Несколько аудио/видео либо PDF, PPTX, DOCX, TXT, Markdown загружаются частями
  в приватное хранилище. Длительность документов не запрашивается. Запуск явный.
- Сервер извлекает текст, затем по выбранному результату создаёт конспект и карточки.
  Последовательность продолжает worker, браузер не обязан оставаться открытым после загрузки.
  Повтор генерации использует стабильный ключ, очередь восстанавливается периодическим worker.
- Расшифровка — дополнительный результат, источники доступны рядом с конспектом.
  Существующие задания, редактирование текста, выгрузка TXT/MD/JSON сохранены.
- Визуальный редактор, автосохранение, черновик в текущей сессии браузера, проверка
  ревизии, история текста. Конспект и добавленный урок используют `course_articles.body`.
- Карточки можно создать позже по выбранной версии конспекта. Созданный набор
  остаётся самостоятельным; последующие правки текста его не перезаписывают.
- Pro: запрос по статье или выделению → отдельное предложение → применить/отменить.
  Повтор применения идемпотентен. Устаревшее предложение отклоняется. Предложения
  не публикуются через endpoint публичного конспекта и sitemap.
- Автоматически созданный конспект закрыт. При выборе существующего курса он наследует
  доступ курса; открытые курсы помечены. Публикацию отдельной версии можно изменить позже.
- Удаляется задача со всеми источниками; уроки курса и сохранённые наборы остаются.
  Обрабатываемую задачу нельзя удалить по частям. Ошибка извлечения требует исправленного
  файла, ошибку генерации можно повторить без повторной загрузки готовых источников.
- Задачи и история редакций входят в существующий экспорт аккаунта.

## Технические границы

Миграция `ai_assistant` добавляет задачи, историю и связь конспекта с уроком, дополняет
снимки тарифов новыми правами. Проверки выполняются через Entitlements. API-клиент
перегенерирован из OpenAPI. Для PDF добавлен `pypdf`; Office разбирается через
`defusedxml`, без выполнения содержимого. Парсер запускается отдельным процессом
с ограничением времени и памяти. Документ — до 25 МБ, PDF — до 300 страниц,
суммарный вход генерации — до 100 000 символов. Извлечение текста не тратит минуты.

Нет OCR для сканов, загрузки ссылок, старых бинарных DOC/PPT, генерации растровых
иллюстраций. Дополнительная настройка предлагает **текстовые схемы и таблицы**.
Исходные файлы удаляются после обработки по существующему жизненному циклу;
доступны извлечённый текст и структурированный результат распознавания.

## Проверки

- 32 backend-теста: новый помощник и парсеры, существующие генерации, расшифровки,
  редактор курса. Изолированная БД `remora_ai_test`, отдельная Redis DB, локальная почта.
  Проверены чужие источники/результаты, лимит, продолжение цепочки, удаление группы,
  Pro-доступ, предпросмотр, конфликт ревизий, повтор применения и единый текст курса.
- 33 frontend-теста: новая форма, ручной запуск, два документа на Plus, превышение
  лимита, выгрузка частями, автосохранение без потери свежей правки, черновик, версии,
  генерация, визуальный редактор и Markdown.
- Ruff, mypy (201 модуль), ESLint, TypeScript, форматирование, production-сборка Vite.
  В сборке остаются предупреждения о крупных чанках и browser-external модулях Pyodide;
  это существующая подсистема практики, не ошибка сборки помощника.
- В браузере: настоящий вход тестового пользователя, два TXT через multipart/S3/worker,
  оба извлечённых текста, одна запись истории, минуты без списания; визуальная правка
  с автосохранением и последующим открытием; создание курса и ссылка на общий урок;
  панель ИИ, диалог истории и Escape. Проверены 320, 390, 1440 и 3840 px, обе темы.
  На 4K контент ограничен шириной 1380 px, на 320–390 px нет горизонтального переполнения.
- Скриншоты `review/*.jpg` локальные, игнорируются Git. В интерфейсе использована
  существующая иллюстрация папки, новые бренд-ассеты не создавались.

Внешние SpeechKit/OpenAI в тестах подменены. Живой прогон платной генерации на новых
источниках не выполнялся: локальный стек изолирован от внешней сети. Перед выпуском
нужен отдельный прогон с провайдерами. Миграция применена только локально; push/deploy
не выполнялись. По отдельной команде пользователя подготовлен самостоятельный коммит
помощника: общие файлы включены частично, посторонние изменения остаются в рабочей копии.
Включены необходимые общие компоненты уведомлений о подписке и иллюстрация папки.
