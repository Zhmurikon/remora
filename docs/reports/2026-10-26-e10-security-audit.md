# Аудит безопасности E10 — 26 октября 2026

## Объём

Проверены все роутеры `/api/v1`, сервисы доступа к пользовательским ресурсам, прямые и
импортные загрузки изображений, вывод UGC в SPA и SSR, PDF и текстовые экспорты, а также
актуальные зависимости Python и JavaScript. Проверка выполнялась по категориям OWASP Top 10;
внешнее динамическое сканирование публичного стенда в этот срез не входит, поскольку серверные
действия требуют отдельного согласия владельца.

## Права доступа

Каждый личный ресурс выбирается вместе с `user_id`/`owner_id` либо проходит явную проверку в
сервисном слое. Публичность курса повторно проверяется по состоянию курса, публикации и
модерации; знание UUID вложенной статьи, набора, карточки или медиа не обходит это правило.
Служебные маршруты разделены на `moderator` и `admin`, бан пользователя доступен только
администратору.

Добавлен сквозной тест `test_access_matrix.py`: чужие UUID папки, набора, карточек, курса,
редактора курса, изображения, попытки теста, API-токена и задания полного экспорта возвращают
только 403/404. Дополнительно прогнаны 137 существующих тестов идентичности, контента, курсов,
библиотеки, обучения, импорта, ботов, MCP, практики, экспорта и медиа. Отдельно проверён запрет
озвучивания чужой карточки.

## Загрузки

- Лимит проверяется по заголовку и фактически прочитанному телу; размер и число пикселей имеют
  независимые пределы.
- Фактический тип растра определяется Pillow, расширению и заявленному MIME доверия нет.
- JPEG, PNG, WebP и GIF после проверки повторно кодируются в однокадровый WebP. EXIF, ICC,
  комментарии, имена файлов и дополнительные кадры не сохраняются.
- Пользовательское имя файла больше не участвует в ключе S3; ключ строится из UUID.
- SVG разбирается `defusedxml`, допускает только закрытый список элементов и атрибутов,
  удаляет обработчики, `style`, внешние URL, `foreignObject`, `script` и XML-сущности.
- Импорт Anki использует тот же медиапайплайн; исходный архив хранится под каноническим ключом
  UUID и удаляется после обработки.

## Санитизация UGC

- Обычный текст карточек и все SSR-поля выводятся React с экранированием.
- Теория разбирается `markdown-it` с `html: false`; ссылки разрешены только для `http(s)` и
  `mailto`, получают `noopener noreferrer nofollow`; изображения принимают только `media:UUID`
  из серверной карты подписанных ссылок.
- KaTeX работает с `trust: false`; Shiki получает только закрытый список языков и экранирует
  исходный код. Тесты отклоняют `javascript:`, сырой HTML, обработчики событий и внешние
  изображения.
- JSON-LD заменяет `<` на `\u003c`, поэтому пользовательский текст не закрывает `script`.
- PDF рисует строки через ReportLab, TXT/CSV экранируют разделители и кавычки, Anki HTML
  экранирует `&`, `<`, `>`, табуляции и переносы. ZIP пишет JSON через сериализатор, не HTML.

## Зависимости

Обновлены Next.js, Vite, Vitest, Markdown-it и PostCSS; уязвимые транзитивные версии закреплены
через `pnpm.overrides`. После обновления `pnpm audit --audit-level high` и `pip-audit --local`
не находят известных уязвимостей.

## Результат по OWASP Top 10

| Категория | Результат |
| --- | --- |
| A01 Broken Access Control | Закрыто серверными проверками и матрицей чужих UUID |
| A02 Cryptographic Failures | Пароли Argon2id, токены хешируются; ротация секретов — отдельный срез E10 |
| A03 Injection | ORM-параметры, закрытые схемы, безопасный Markdown/SVG/экспорт |
| A04 Insecure Design | Сервисные роли, идемпотентность, постмодерация и аудит выделены явно |
| A05 Security Misconfiguration | Защитные заголовки и CSP — следующий срез E10 |
| A06 Vulnerable Components | Известных уязвимостей после обновления не найдено |
| A07 Identification and Authentication Failures | Короткий access JWT, ротация refresh, отзыв семей; 2FA — отдельный срез E10 |
| A08 Software and Data Integrity Failures | Фиксированный lockfile, проверка содержимого загрузок, схема API коммитится |
| A09 Security Logging and Monitoring Failures | `audit_log`, `moderation_actions`, `request_id`; внешние алерты относятся к E11 |
| A10 SSRF | Удалённые изображения агента запрещают приватные/локальные адреса и повторно проверяют DNS |

## Остаётся внешней проверкой

После разрешения на работу со стендом нужно запустить OWASP ZAP или эквивалент против реального
TLS-домена и приложить отчёт без критических и высоких находок. Локальные тесты не заменяют
проверку конфигурации reverse proxy, DNS и фактических заголовков на границе.
