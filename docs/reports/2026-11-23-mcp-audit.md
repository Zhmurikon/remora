Проверены [публичный коннектор и навык `remora-author`](https://github.com/Zhmurikon/remora-ai-integrations/tree/cacddc2c57637f425ecf8ac93936c62302fc243e) на коммите `cacddc2` и локальный API Запоминальни на коммите `e423a7d`. Внешний ассистент готовит содержание, MCP передаёт его в Запоминальню. Проверка охватывает этот путь. Встроенный ИИ-помощник и вызовы его провайдеров находятся за её пределами.

## Какие возможности расширить

1. **Подключение из веб-чата.** Для пользователя без Python и локального MCP-клиента полезнее всего размещённый HTTPS MCP с индивидуальным входом и выбором прав на чтение, запись и публикацию. Сейчас репозиторий запускает процесс через stdio. Для пилота с ChatGPT также существует Secure MCP Tunnel. [Подключение в ChatGPT](https://developers.openai.com/plugins/deploy/connect-chatgpt), [удалённые коннекторы Claude](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).
2. **Проверка подключения без записи.** Один вызов мог бы показать доступные права текущего токена, доступность приватных материалов, остаток недельной квоты и срок её обновления. Его стоит поставить последним шагом установки. Это позволит отличать успешный запуск процесса от работающей авторизации.
3. **Точечное редактирование.** Перемещение набора, изменение его названия и добавление отдельных карточек по ревизии позволят обходиться без передачи всей колоды. Особую ценность это даёт большим наборам и карточкам с изображениями или историей повторений.
4. **Проверка поведения самого навыка.** Закрепить несколько одинаковых заданий для Codex и Claude с измеримым результатом. Например, «покажи черновик» означает ноль записей, «сохрани приватно» на Free завершается явным отказом, а исправление одной карточки сохраняет остальные ID и поля. Отдельно оценивать верность исходнику и однозначность вопросов в обоих направлениях.


## Исправления после аудита

Агентский API теперь сохраняет карточки при отсутствии поля `cards` на верхнем уровне набора и в материалах существующих статей. Массив по-прежнему заменяет колоду, а `[]` очищает её. За одинаковый повтор списывается одна недельная операция. MCP передаёт `text_only` при копировании урока. MCP и агентский API проверяют обе стороны передаваемых карточек, сохраняя отступы и переносы в коде.

На отдельном локальном стенде прошли 45 тестов API, включая конкурентный повтор при расходе 499/500, сохранность карточек и строки прогресса, вложенный набор и ошибку валидации по пути до стороны карточки. У коннектора прошли 125 автономных тестов и один сквозной тест через stdio, HTTP, PostgreSQL и MinIO. Сквозной сценарий проверяет расход квоты, перенос в папку, отказ пустой стороне и копирование теории с независимой иллюстрацией и пустой колодой.
