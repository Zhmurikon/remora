# Проверка производительности публичных страниц — 29 сентября 2026

Полевые данные CrUX для молодого сайта ещё не накоплены, а PageSpeed Insights API во время
проверки отвечал ограничением квоты. Поэтому исходная точка снята локальным Lighthouse в
мобильном и настольном профилях против production-сайта после включения серверного кэша.

| Каталог | mobile | 92 | 2,65 с | 218 мс | 0 |
| Подборка | mobile | 98 | 1,57 с | 116 мс | 0 |
| Крупный курс, 388 карточек | mobile | 45 | 4,52 с | 3,42 с | 0 |

Кэш постраничной выдачи карточек не нужен: карточки загружаются по требованию и сверяют
revision, а узкое место крупного курса возникает раньше — браузер повторно разбирает и
гидратирует всю Markdown-теорию. Эксперимент с удалением глобальной клиентской границы
результат не улучшил и был отменён. Следующая оптимизация — серверный рендер теории на
публичной странице курса без отправки исходного Markdown и парсера в браузер.
