# Концепты страницы блога

Три статичных макета при ширине 1440 px. Рубрики, названия, даты и время чтения взяты из опубликованного блога 16 ноября 2026 года. Обложки на макетах иллюстрируют выбранное направление. При вёрстке источником обложек остаются данные публикаций, для статей без изображения используется резервная схема.

- [А · На полях](a-margins.png). Предметы по краям первого экрана обрамляют заголовок. Ниже читатель выбирает рубрику слева или просматривает аннотации в ленте справа.
- [Б · Журнальный разворот](b-journal.png). Верхняя полоса отдана самой свежей статье. Остальные материалы образуют две колонки, указатель тем расположен под заголовком.
- [В · Картотека](c-index.png). Слева расположены введение и указатель тем. Справа в папке собраны заголовки по рубрикам, рядом с каждым видны дата и время чтения.

Знак и рисунки канцелярии взяты из [лекционного демо](../../../apps/web/public/lecture-demo/). Иллюстрация для статьи о формулах сгенерирована встроенным ImageGen.
