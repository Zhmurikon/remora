# Карандаш в задачнике

[Статичный hero «Учебный стол»](../concepts/hero/1-desk.png) · [Видеопревью](desk.mp4)

Наведение на рисунок стола запускает один жест. Карандаш поднимается к третьей строке, обводит квадрат, ставит в нём галочку и возвращается под задачник. Новая отметка ненадолго остаётся на странице. Заголовок, абзац, стопка книг и обе страницы задачника неподвижны.

| От начала жеста | Что видно |
| --- | --- |
| 0–530 мс | Карандаш приподнимается, поворачивается на 12° и подводит грифель к началу строки. |
| 530–1240 мс | Грифель обводит четыре стороны квадрата по наклону листа. |
| 1240–1820 мс | Карандаш переходит внутрь квадрата и выводит галочку двумя штрихами. |
| 1820–2420 мс | Карандаш приподнимается над бумагой и ложится на прежнее место. |
| 2420–3420 мс | Готовая отметка остаётся на 720 мс и гаснет за 280 мс. |

В начале и конце ролика оставлены неподвижные кадры для сравнения с макетом.

## Для вёрстки

- Сохранить размеры и положение задачника в [макете](../concepts/hero/1-desk.png). Взять тот же исходный рисунок [news-test.webp](../../../apps/web/public/lecture-demo/news-test.webp). Для неподвижной бумаги и подвижного карандаша использовать взаимодополняющие маски в координатах 427 × 285. Поворот всей тетради относится к общему контейнеру. В светлой и тёмной темах оба слоя получают одинаковую обработку цвета.
- Совместить кончик грифеля с точкой (155, 264). Квадрат проходит через (96, 182), (119, 177), (124, 197), (100, 202) и замыкается в начальной точке. Галочка идёт от (101, 187) через (108, 192) до (122, 174). Положение грифеля и длину видимого штриха вычислять по одной траектории.
- На устройстве с точным указателем вход в область всей иллюстрации запускает один цикл. При уходе указателя сцена доигрывает до исходного кадра. Удержание указателя и переход между предметами внутри рисунка не запускают повтор. Следующий вход после окончания жеста запускает его снова.
- При касании, без JavaScript и при `prefers-reduced-motion: reduce` показывать исходный рисунок. Исключить сцену из озвучивания и обхода клавишей Tab. Доступ к оглавлению и ленте статей сохраняется во время жеста.
- Для ссылок оглавления и заголовков статей достаточно подчёркивания при наведении и видимой рамки при клавиатурном фокусе. Текст ленты доступен сразу при загрузке.
