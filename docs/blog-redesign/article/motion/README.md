# Сгиб титульного листа

[Выбранная композиция В](../concepts/c-cover.png) · [Видеопревью на примере статьи об иностранных словах](title-sheet.mp4)

При наведении на обложку нижний правый угол титульного листа приподнимается. Видны оборот бумаги, его тень и край второго листа. После короткой паузы угол расправляется. Коллаж, название и начало статьи остаются на месте.

| Время от наведения | Движение |
| --- | --- |
| 0–680 мс | Сгиб плавно раскрывается. Угол занимает до 77 × 62 px при ширине страницы 1440 px. |
| 680–1030 мс | Короткая пауза в верхнем положении. |
| 1030–1720 мс | Угол опускается, тень укорачивается и исчезает. |

В ролике перед жестом и после него оставлены неподвижные кадры.

## При вёрстке

- Рисовать сгиб в локальных координатах листа. Наклон листа общий для рамки, оборота и тени. Заголовок остаётся обычным HTML-текстом. Для длинного названия зарезервировать место под угол или уменьшить сгиб.
- Запускать жест один раз при входе точного указателя в обложку. Если указатель сразу ушёл, дать листу расправиться. Повторить при следующем входе после завершения жеста.
- На сенсорном экране, без JavaScript и при сокращённом движении показывать плоский лист. Декоративный угол исключить из озвучивания и порядка Tab. В тёмной теме использовать цвета бумаги и рамки из соответствующей палитры.
- Сохранить анимации заголовков и ссылок блога. У ссылок оглавления и источников оставить видимый клавиатурный фокус, у демо — обычный переход по ссылке. Переход к разделу работает независимо от состояния обложки.
